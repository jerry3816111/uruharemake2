In the private C raw trace, M31 rejected its surface, M32 selected `私は…決めたんだね。` with canonical `subject_jp=私`, the base visible guard marked `source_unverified/direct_echo_certificates_not_verified` and replaced that self-attributing echo, then M39 accepted the safe generic reply unchanged. The C product entry had no `mixed_act_lineage_p4` receipt, which the base echo guard requires. C8 additionally begins `訂正、`, which that guard explicitly excludes; adding producer lineage alone would not solve its correction act. This is a source-to-surface authority and act-recognition gap, **not** evidence that memory retrieval failed or that the base identity guard should be relaxed.

Hypothesis: an opt-in, narrow authority that derives its acknowledgment from the **actual current User event**, selects it before speech, and binds it through final visible/writeback checks can replace generic clarification with a concrete, actor-correct Japanese reply for unquoted dated-place decision statements. A separately recorded `correction_reported` subtype can acknowledge an explicit correction without deciding which prior claim it supersedes. Failure if the fresh D positive statements still receive a generic question, if User `私` becomes Uruha `うち`, if any negative control is promoted into a direct User decision, or if visible/history/episode/source receipts diverge. The two subtypes must be reported separately, not merged into one score.

A correction is a **reported correction**, never automatic replacement of prior claims or selection of a stable current place. Unsupported input stays on the prior path and the base actor guard remains fail-closed.
