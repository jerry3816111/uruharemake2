## Before, intervention and single attributable variable

Before S3, a correctly linked two-action request generated one shape-valid
terminal reply but lost the quote year, changed `調整中` to `決めてない`, and used
`その日` for a *different* recall date. The direct quote-to-free-rewrite-to-
concatenation method has no pre-surface per-act semantic obligations. Typed
lineage proves producers, not delivered meaning.

Intervention: for **already eligible** bounded mixed requests, replace only
the terminal *realization method* with an event/source-bound two-act ledger.
The supported quote class and transform are exactly as specified in the
design review: validated absolute date + `集合場所はまだ` + one of
`相談中|調整中|確認中` + `です`; change the final copula only to `なんだ`, retaining
all preceding characters. Recheck the raw quote span/digest and require raw
quote == NFKC quote; a noncanonical quote abstains rather than claiming
character-level preservation after normalization. Independently render the recall act from the
existing certificate, naming its **outer** date in unknown states. Bind both
act texts and provenance to event/action IDs before composing the final
candidate; final guard rederives source/ledger integrity. Opt-in flag; no
added model call for this class. Unsupported cases abstain from new terminal
priority without falling back to the old free mixed rewrite under this flag.
This is not intended to solve general paraphrasing or all mixed acts.

Do not change M31/M32, legacy source classification/certificates, producer
lineage, single-rewrite path, protected route, model/settings, old frozen data,
formal DB, baseline or memory writes. The ledger may be a new sidecar module
and minimal calls from `uruha_typed_mixed_atomic_delivery_p4.py`; additive,
receipt-verified graph projection is allowed. Other allowed files: one focused
test file, thin opt-in Web entry/controller only if necessary, product SHA,
result report, and top of `CURRENT_TASK.md`. Review any changed file against
this list. No raw quoted text or source value in new public graph details.
