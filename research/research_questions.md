# Research questions

1. **RQ1 Reconstruction:** Can the proposed model reconstruct known historical public behavior better than LLM-only and RAG baselines?
2. **RQ2 Future prediction:** Does it improve prediction of unseen future behavior under strict temporal holdout?
3. **RQ3 Interpretability:** Do explicit states yield explanations that are faithful under intervention?
4. **RQ4 Component contribution:** Which memory, emotion, personality, relationship, preference, goal, habit, context, and temporal-transition components materially affect prediction?
5. **RQ5 Intervention:** Do controlled state changes cause systematic, interpretable changes in behavior probability?
6. **RQ6 Data scaling:** How does predictive performance change with longitudinal coverage, and where do gains saturate?
7. **RQ7 Transfer:** Can the same state architecture model another person by changing evidence and person-specific parameters rather than core logic?

M1 answers none of these conclusively. It establishes the reproducible temporal benchmark and baseline floor required to test them.
