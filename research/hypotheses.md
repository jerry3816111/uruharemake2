# Falsifiable hypotheses

- **H1:** Hybrid explicit-state modeling improves temporal-holdout behavior prediction over pure LLM and simple RAG.
- **H2:** Structured memory improves prediction over raw full-history retrieval as irrelevant history grows.
- **H3:** Relationship, memory, and habit variables add predictive value in interaction-heavy contexts.
- **H4:** Explicit temporal state transition outperforms static persona descriptions on longitudinal data.
- **H5:** Explanations bound to actual state variables and intervention effects are more faithful than post-hoc explanations.
- **H6:** Additional historical coverage improves prediction with diminishing returns.
- **H7:** A person-independent architecture transfers to another individual without person-specific core-logic rewrites.

Failure to beat a strong baseline is an acceptable scientific result. Hypotheses, gates, metrics, and held-out answers must not be changed after outputs are observed.
