# P4 stateful admission f2：repair-cue 接線後第一次真 Safari 的事前計畫

狀態：**source-only 事前凍結；尚未執行 f2 模型或 Safari Send**。這是作者撰寫的產品診斷題，不是正式 holdout、人評或與 LLM 的公平對照。f0 是 pre-Send strict FAIL；f1 是 opt-in 接線前零模型 route FAIL，修後只可作 regression；兩題均不重送、不改判。接線結果 `analysis/p4_repair_cue_m29_chain_integration_zero_model_2026-10-24.md` 只證明選對 speech act，沒有新真模型可見回覆。本題依 `research/p4_turn_admission_post_f0_design_review_2026-10-24.md` 的 B 主張：在**實際 pre-state**下可歸因的 browser 輪，不宣稱 pristine tick0 或背景活動無影響。

## 問題、唯一變因與資料邊界

唯一新的產品輸入是 `datasets/p4_turn_admission_stateful_f2_probe_2026-10-24.json` 的一次新使用者輪；不改 Brain、overlay、planner、guard、背景 scheduler、journal/schema、Web、模型、baseline 或正式資料。輸入為「部屋の家具の置き方を考えて、決めた。今は一言だけ励まして。」：與舊小說／庭院／發表／列名題逐字不同，語境為自己做家具配置決定，`考えて` 中的 `え` 不是獨立「え？」追問。Git tracked corpus 對整句、`部屋の家具の置き方`、`考えて、決めた` 精確搜尋各 0 命中；既有 classifier 只讀得到 `direct / brief_encouragement`。這仍是與舊題共享明示鼓勵格式的開發診斷，不宣稱 open-domain 泛化。

執行環境固定現行 commit `fe7a69955363f92881ec0b380a2a1cc61bcb5919` 的 opt-in M29 product entry；`--direct-act-arm control --repair-cue-boundary --turn-admission-journal --product-port 7929 start --mode product`。新 0700 私有 root，loopback-only，`qwen2.5:7b` digest `845dbda0ea48ed749caafd9e6037047aa19acfcfd82e704d7ca97d631a0b697e`、原產品生成參數、官方 ONNX digest `913d7300ceae3b2dbc2c50d1de4baacab4be7b9380491c27fab7418616a16ec3`；上限 3 completed Brain user-turn generations、2,000 provider tokens、20 秒 user wait、Safari Send **一次、0 retry**。成本須分 Brain-turn、background、Web-delivery；現有 Web delivery 額外 Chroma 操作無獨立 ledger，必標 `unknown/not measured`，即使其餘全部通過也不得稱 full production-cost PASS。正式私有 DB、原始 dirty checkout、無關 output 不碰。

## 順序與硬性停止條件

1. **先封存**本計畫／題本／preimplementation SHA／任務卡並 commit、push、核 PR #435 exact head，之後才准 f2 的 fake full-turn 或真模型。source-only classifier 不代表 full route。用真 RightBrain＋假 LeftBrain 的隔離 `run_turn_debug` 預檢 M29 `brief_encouragement`、M33 `not_applicable`、M18 不接管、M21 `full_planner` 且 compact completed、scene `support`、act `direct_chat_answer`、final＝episode、1 fake call；任一失敗即不啟真產品，留下 FAIL。不可改題或 gold 追分。
2. 先核 port 7929 空閒；新 root `prepare`、私有官方 ONNX 封網預熱；無 journal／無對話零輪 rehearsal，要求 same-final-PID HTTP ready、planned stop 後 exact PID 退出且 port vacant。再用上述三個 opt-in flag 啟正式產品，要求 same-final-PID ready、model digest、session／reset0、active `memory_db`、brain ready 與 user episode/profile 0。暫時 listener readiness race 只可在**同 PID**複查，不可重啟同題掩蓋。
3. ready/T0 與 Send 前 Tpre 各保存隔離 DB **regular-file tree**（相對路徑、size、SHA-256、monotonic 取樣前後界線）；拒絕 symlink、root escape、取樣時漂移，兩個 tree 必須 byte-equivalent。Tpre 同 PID/session/reset0/DB、`human_submission_finish_count=0`、已知非負 tick；tick>0 揭露為 pre-state 而非 pristine。到 Tpre 為止的 journal 只准已完成、同 PID/session/reset/DB、raw-free、連續序號的 `background_start/end` pairs；ledger coverage 完整、0 error/unknown independent worker、方法層 add/update/upsert/delete returned/error 皆0。`passive_decay` 的 in-memory 指紋變更可作明示 pre-state，不得冒稱背景無影響；DB tree drift、未配對或未知 writer 即**不 Send**。
4. 只在原生 Safari 新 tab 確認 exact input、session、未送狀態；Tpre monotonic 取樣後目標 ≤10 秒點 Send。若無可核點擊時間或 Tpre 不合格，產品 gate FAIL；若 Tpre 取樣不確定窗口至 server `arrival` 之間有任何 background event 或順序不明，**即使已 Send 仍 strict FAIL、不得重送**。`arrival` 需 browser source／同 opaque submission ID/PID/session/reset；其 DB/tick 在現有 schema 為 null，不回填。`admission_snapshot` 起核真 DB/tick/fingerprints，然後同 ID `cognition_start`→`cognition_end(completed)`→`terminal(delivered)` 連續、無 background/proactive 交錯、timeout/error/invalid 或 state drift。server `delivered` 不等於 Safari DOM ACK。
5. 真回覆事前 gold：短且自然的日文，承接**使用者已決定家具擺放方式**這個可觀察事實，給一言鼓勵；不改成未要求的整理建議、追問、泛用休息句，也不編睡眠、疲憊、私人感受或過往。公開 Uruha persona 邊界內，不冒充真人、不作錯誤身分聲稱；本題不能正向證明 self identity。泡泡＝私有 raw＝guard final＝graph utterance＝隔離 episode，Safari 原生 node graph 至少可核 input→retrieval→decision→utterance→writeback 同輪內容／連線；保存可重核 native PNG/AX 或同等原生視覺證據，HTML replay 不能替代。selected core 若有終止標點，要求無 `！。`／`？。`／`。。` 及標點引發的 guard fallback，否則此項 `not_exercised`。
6. 核 Brain user-turn actual model calls/tokens/wait/vector ops、背景 pair/read/gen、journal bytes/events、隔離 DB episode/profile 前後與完整性。Brain-turn 超上限或缺帳、可見來源／圖／日文任一 gate 不符即 strict FAIL；Web delivery 追加向量成本若無收據保持 unknown。只停 exact PID、核 port vacant、只關本次新 Safari tab，保留私有原件 hash。UI 工具拒絕時 Web 層 pending，不繞過。所有失敗與分母寫入報告，無條件重試禁止。

只有以上窄義 stateful admission＋可見品質＋Brain-turn 成本同時有原件時，才可稱 f2 narrow product PASS；不能外推為完整 runtime 成本、長期記憶／預測校準、同模型優勢、真人被理解感、temporal holdout、VRM／Function Calling 統一驗收或完整人類反應方程式。若未過，保留反例再前瞻設計單一原因修正，不把 f2 改標或換近似句追分。
