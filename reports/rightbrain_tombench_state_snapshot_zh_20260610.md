# F 右腦補強對 ToMBench 的真正意義

日期：2026-06-10

## 第 0 頁：上一週報告中的「答案消失」頁

這一頁保留上一週報告中最重要的觀察：完整聊天流程不是完全沒有思考，而是 final reply 幾乎沒有把可解析的選項答案說出來。

| 指標 | 數字 | 意思 |
|---|---:|---|
| final reply 可解析 | 1 / 50 = 2% | 最後回覆只有 1 題能被看成選項答案 |
| final reply 答對 | 0 / 50 = 0% | 完整聊天最後輸出沒有成功答對 |
| final reply 答案消失 / 不可解析 | 49 / 50 = 98% | 這就是 F 需要改的主要原因 |
| 左腦 core message 可解析 | 16 / 50 = 32% | 內部有一部分答案曾經存在，但沒有穩定活到 final reply |
| 左腦 core message 答對 | 6 / 50 = 12% | 即使保留答案，D/E 本身仍有推理正確率問題 |

實際例子：

| 題目 | 官方答案 | 左腦內部曾出現 | final reply 實際輸出 | 問題 |
|---|---|---|---|---|
| Strange Story Task:227 | B | `二番だろ。` | `何の話かもう一回言えって。そこ分かれば返せる。` | 左腦答案 B 消失，變成澄清句 |
| Hinting Task Test:92 | D | `四番だろ。` | `何の話かもう一回言えって。そこ分かれば返せる。` | 左腦答案 D 消失，final reply 解析不到 |
| Scalar Implicature Test:112 | D | `四番だろ。` | `何の話かもう一回言えって。そこ分かれば返せる。` | 左腦答案 D 消失，變成泛用反問 |

一句話：F 的問題不是不會推理，而是會把已經出現的答案洗掉。

## 第 1 頁：本週報告先講結論

F 不會讓純 ToMBench MCQ 推理分直接變高。

F 的意義是：D/E 已經想出的答案，不要在 final reply 消失。

| 問題 | 結論 |
|---|---|
| F 會讓系統更會推理嗎？ | 不會。推理主要是 D 左腦和 E 候選檢查。 |
| F 對純選擇題模式有幫助嗎？ | 幾乎沒有。純 MCQ 只要選 A/B/C/D，不需要自然聊天輸出。 |
| 那為什麼要改 F？ | 因為完整聊天系統最後輸出是 F 產生的。F 如果洗掉答案，ToMBench 和使用者都看不到。 |
| F 的 ToMBench 相關目標是什麼？ | 提高答案保留率、final reply 可解析率，而不是提高推理正確率。 |

一句話：D/E 負責想得對不對；F 負責想好的答案有沒有被說出來。

## 第 2 頁：F 前 / F 後流程對照

外層流程固定，不是整條流程換掉。

```text
A 讀入題目 -> D/E 思考與檢查 -> F 右腦輸出 -> final reply
```

真正改的是 F 內部。

| 比較 | F 做之前 | F 做之後 |
|---|---|---|
| F 的角色 | 自由改寫器 | 受控輸出器 |
| 內部流程 | 直接自然化 / 直接改寫 | 輸出契約 -> 多候選 -> 排序 -> 品質 gate |
| 主要風險 | 把 A/B/C/D 洗成反問、澄清、安慰、普通聊天 | 強制保留必要答案、必要語意與禁止內容 |
| ToMBench 意義 | 左腦可能想過，但 final reply 看不到答案 | final reply 更可能保留選項或核心答案 |

一句話：F 前後的差異不是「有沒有完整聊天」，而是「完整聊天最後一句有沒有保留答案」。

## 第 3 頁：做之前 / 做之後數據對照

這裡要分清楚：做之後目前最直接能證明的是「答案保留能力提高」，不是「完整聊天 ToMBench 正式分數已經提高」。

| 條件 | 可解析率 | 答對率 | 意思 |
|---|---:|---:|---|
| 做之前：原本 final reply | 1 / 50 = 2% | 0 / 50 = 0% | 答案幾乎都在 F 輸出時消失 |
| 做之後證據 1：契約重放 | 16 / 50 = 32% | 6 / 50 = 12% | 只要 F 保留左腦已存在的選項，可解析率會上升 |
| 做之後證據 2：右腦 holdout v2 | 輸出契約 100% | 語意保留 100% | F 在專用右腦測試中能保留必要語意 |
| 做之後證據 3：污染與重複 | 污染 0% | 重複 0% | F 的表面輸出更穩定 |

注意：契約重放不是正式新分數，而是用舊 log 檢查「如果 F 不把左腦選項洗掉，會發生什麼」。

一句話：F 改造的效果要先看「答案有沒有被保留」，不是先看純 MCQ 分數有沒有提高。

## 第 4 頁：F 到底做了什麼

| F 補強項目 | 做了什麼 | 對 ToMBench 的用處 |
|---|---|---|
| 輸出契約 | 先規定 final reply 必須保留答案、必要語意、禁止污染 | 防止選項 A/B/C/D 在最後輸出消失 |
| 多候選 | 不只生一句，而是生幾種可能輸出 | 避免第一句剛好是反問或模板句 |
| 排序器 | 選最完整、最符合契約的候選 | 讓「有答案的句子」優先進 final reply |
| 品質 gate | 擋掉漏答案、漏語意、中文混入、重複、內部文字 | 壞輸出不能直接出現在 final reply |
| raw model gate | raw 模型候選不能直接上線，要先通過檢查 | 避免模型把答案洗成自然但無效的聊天句 |

最後結論：

| 可以主張 | 不能主張 |
|---|---|
| F 補強是為了修答案消失 | F 會直接提高純 ToMBench 推理分 |
| 之前 final reply 有 98% 不可解析，確實有 F 輸出問題 | 完整聊天 ABCDEFG 已經能通過 ToMBench |
| 契約重放顯示可解析率可從 2% 到 32% | F 可以取代 D/E 做社會推理 |

最短總結：ToMBench 純分數要靠 D/E；完整聊天能不能把答案說出來，才是 F 的責任。
