## 防止資料洩漏

- 先凍結官方版本、整段對話分割、抽樣演算法及成功門檻，再解析資料。
- 四段完整對話作一次性 holdout，六段完整對話保留；同一段對話不跨組。
- 提交到 Git 的 case manifest 只保存 ID、來源位置與雜湊，不保存官方題目、答案或對話全文。
- 模型只看到問題與一筆記憶，不會看到答案、證據 ID、題型或預期標籤。

## 證據邊界

這一輪只測「來源保留投影能否在另一個正式資料集中保留單段明確記憶」。通過也不代表完整 LoCoMo 分數、完整聊天系統、人物相似度或正式上線已通過。
