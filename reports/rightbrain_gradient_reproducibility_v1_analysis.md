# RightBrain 梯度重現性稽核：分析

## 結論

三個隔離 Python process 都重建出完全相同的 total gradient norm：
`2.878972291946411`。總 norm 變異係數為 `0`、最大／最小比為 `1.0`，
三組 projection × LoRA-side profile 的兩兩 cosine 都是 `1.0`。

因此，**目前凍結的 gradient-only harness 跨 process 可完全重現**，且穩定
吻合 AdamW 診斷中的 `2.878972`，不吻合先前遙測的 `403.728180`。先前
`403.728180` 必須視為尚未解釋的舊執行異常值，不能再作為「嚴重裁切」
或調整訓練參數的可靠證據。

## 舊結果差異位置

舊 `403.728180` 並非只在單一 layer 或 projection 偏大，而是在多個
LoRA-B 群組同時被放大。例如：

| 群組 | 舊 norm | 本次穩定 norm |
|---|---:|---:|
| up_proj / LoRA-B | 223.1766 | 1.5374 |
| gate_proj / LoRA-B | 174.7180 | 1.1943 |
| v_proj / LoRA-B | 173.8831 | 1.3087 |
| o_proj / LoRA-B | 144.7581 | 1.1637 |
| down_proj / LoRA-B | 112.6878 | 0.6781 |

這表示它不像單一參數離群值，但目前證據仍不足以把原因指定為 MPS、
gradient checkpointing、dropout、非同步執行或量測錯誤中的任何一項。

## 研究判定

可以主張：

- 目前單一凍結 harness 的同批 backward 在三個隔離 process 中完全可重現。
- 可重現尺度是 `2.878972`，而不是 `403.728180`。
- 先前以 `403.728180 / 0.3` 推導的 `1345.76x` 與 `0.000743` 裁切係數
  不再具有足夠重現證據。

不能主張：

- 已找到舊 `403.728180` 的程式或環境根因。
- 已證明 max_norm、learning rate 或 AdamW 應如何修改。
- 已得到任何模型能力、人格相似度或 production 證據。

## 下一個可推翻假設

下一步只稽核舊 `403.728180` 執行路徑：逐項比對當時 harness 的載入順序、
梯度量測時點、環境狀態與產物內容，並用目前可重現的 `2.878972` 作為
控制值。在找到可單獨重現 `403.728180` 的唯一變因前，不恢復 AdamW
裁切效果實驗，也不修改訓練參數。
