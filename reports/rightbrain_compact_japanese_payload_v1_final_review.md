# 右腦精簡日文載荷 V1 最終審查

## 結論

**實驗有效，但精簡日文格式退步。**

| 指標 | 舊格式 | 精簡日文 | 新－舊 |
|---|---:|---:|---:|
| 嚴格有效輸出 | 2/10 | 1/10 | -1 |
| 語言／文字污染 | 4/10 | 7/10 | +3 |
| 必要語意缺失 | 7/10 | 7/10 | 0 |
| 過度禮貌 | 4/10 | 5/10 | +1 |

兩組都使用相同 Qwen2.5-7B base-only、案例、人格策略、seed、解碼、嚴格 gate 與 640 token 配額。所有控制檢查通過，舊格式也精確重現先前的 2/10 基線。

## 這次排除了什麼

新格式的模型 prompt 不含英文字詞，但案例 4 仍出現 `throat`、`Tonight`，案例 5 仍出現中文片段。因此，「英文 JSON 太長而直接污染輸出」不是充分原因；只把契約縮短並翻成日文不能修好目前右腦。

## 決策

`revert_compact_serializer_experiment`

- production 預設維持 `legacy_json_v1`。
- 精簡序列化器只保留為可重現的失敗研究候選，不得上線。
- 不再用這五題微調 prompt，也不加入固定答案或題型捷徑。
- 下一個合理單元是公平篩選本機模型的指令承載能力，而不是繼續人格盲評或訓練。

本結果只否定一個載荷格式假設；它不是人格相似度分數，也不能證明模型能力是唯一根因。
