# 人格策略實際本機模型 pilot V1 最終審查

## 結論

**正式 pilot 失敗，但失敗證據有效，應合併保存。**

| 指標 | 結果 |
|---|---:|
| 實際離線 7B 生成 | 10 |
| 有內容的原始生成 | 10/10 |
| 嚴格有效輸出 | 2/10 |
| 兩組都有效的配對 | 0/5 |
| 原始輸出有差異的配對 | 4/5 |
| 不同正規化輸出 | 9/10 |
| 配置 token 公平性 | 640/640，通過 |
| legacy 固定回覆存取 | 0 |

## 實際發現

人格 policy 確實會改變模型原始生成，但目前右腦無法穩定保留左腦的必要意思。主要失敗是日文混入中文／英文、變成過度禮貌，以及必要語意消失。

其中一個被 gate 接受的疲勞回答也可能是假陽性：`休` 原本代表現在先休息，模型卻用在未來的「休假」，並把下一步改成遠行。這個事後診斷不改正式分數，但證明現有子字串 gate 仍不足以代表語意正確。

## 對照組限制

neutral provider 與 target provider 使用相同的人格微調 adapter。因此這輪只隔離了「policy payload」，並不是完整的「無人格模型」對照。下一個必要實驗是固定其他條件，只比較 base-only 與目前 adapter，確認語言污染和語意遺失主要來自模型、adapter 或 prompt／gate。

本輪不授權盲評、正式人格相似度、訓練或 production 啟用。
