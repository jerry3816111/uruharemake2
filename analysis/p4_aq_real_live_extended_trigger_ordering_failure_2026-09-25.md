# P4-AQ live extended-trigger ordering — preserved failure

## Outcome

P4-AQ is a formal **FAIL**. The prospective offline contract and adjacent
regression passed before the real run, and the first fresh isolated Safari
turn proved the intended ordering repair was live:

- the old M37 detector still missed the input while the fixed P4-AH additive
  trigger matched;
- downstream state changed from 0 to 6 candidates;
- `calibrate_need` was selected under typed `cognitive_overactivity`
  authority;
- P4-AG created a pending binding;
- the temporal graph committed a locked future;
- Safari showed both the P4-AQ ordering node and
  `過去 0｜現在 6候選/選択 calibrate_need｜本輪未來 已封存`;
- there was one durable isolated episode, no added model call, no factual
  memory write, no visible-reply mutation and no raw/private graph leakage.

The same first turn also made the frozen three-turn acceptance impossible:

- released M18 decision status: `not_applied`;
- released product prediction ID: absent;
- P4-AG binding ID: `p4-ag-pred-274521a3e42b4969a4c57b6a`;
- binding ID source: `additive_shadow_identity`;
- P1 prediction sequence: absent;
- P4-AP identity-continuity node: absent.

The run therefore stopped after turn one. Turns two and three were not sent,
and the exposed case will not be rerun.

## Root cause

P4-AQ correctly reapplies the already fixed P4-AH trigger to a copied state
and rebuilds P4-AD/AF/AG/AM in the right causal order. It still supplied P4-AG
with the original released M18 decision. That decision was produced before
the late extension and remained `not_applied`, so it had no product P1 event
identity. P4-AG correctly used its explicit additive fallback identity.

P4-AP is deliberately narrower: it preserves and advances genuine sequential
`p1-N-*` product events only. It must not turn an additive fallback string
into a fake P1 sequence. Consequently there was no identity node, no sequence
1, and no honest basis for next-turn identity continuity.

## Evidence boundary and next split

The result is useful causal evidence for the ordering repair itself: the
fixed late trigger reached candidates, binding and temporal commitment in one
real product turn. It is not evidence that the complete prediction event was
formed, verified or promoted across turns.

The next task, P4-AR, may change only the identity bridge for a late-triggered
shadow decision. It must obtain an authentic product-authoritative P1 event
from the same corrected decision without weakening P1, inventing a sequence,
changing candidate scores, altering the detector or feedback classifier,
changing visible output, adding a model call, or writing psychological
inferences as factual memory. P4-AQ remains a closed exposed failure.

The visible reply `考えが湧き続けるのは無理だよ` also remains a gate-external
quality problem: it is Japanese, but awkward and not evidence of felt
understanding. Ordering success must not be used to claim response quality.
